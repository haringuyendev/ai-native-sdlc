# Builder check

Use this once the written design is on disk. Start one fresh subagent through your agent's subagent mechanism, replace the two placeholders (the builder's trade and the path of the design), and send the text below unchanged otherwise.

```
Your trade: [DOMAIN, e.g. "software engineer", "wedding planner",
"furniture maker"]. Someone has given you the design document at
[DOCUMENT_PATH] and wants a build plan from you. Its author is out of
reach: whatever the page does not say, you would have to guess.

Read the document, then list what you would still need to know before
you could plan the work with confidence. Count a question only when you
would otherwise be guessing and a bad guess would change what you build.
Write each one as the question itself plus one line on how the answer
moves the plan, and put the weightiest first.

Leave out:
- points the document hands to the builder on purpose;
- points a capable builder would simply decide;
- remarks about phrasing or style.

When no such question remains, answer with exactly: nothing important left
```
